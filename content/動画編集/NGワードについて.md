# NGワードについて

![[Pasted image 20260528230035.png]]

> [!warning] テロップ表記のルール
> **Instagramのアカウント停止・制限リスク**を少しでも抑えるため、テロップ内の表記については以下のNGワードルールに沿って記載をお願いいたします。



---



## NGワード一覧

| NGワード | 正しい表記 |
| --- | --- |
| マネタイズ | **マネタイス** |
| 〇〇円 | **〇〇ｴﾝ** |
| 稼げる | **ｶｾゲル** |
| アフィリエイト | **アフリエイト** |
| YouTube | **Y0uTube**（数字の0） |
| LINE | **ライン** |
| 収益化 | **収駅化** |



---



## まとめ

- テロップ内では上記の**置き換え表記**を必ず使用する
- 目的は**アカウント停止・制限リスクの低減**
- 数字の **0** を使う / **カタカナや別の漢字**に置き換える のがポイント
